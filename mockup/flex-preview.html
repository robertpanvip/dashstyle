效果说明

  • 静态行尾预览：每个 flex 属性行尾出现一个小迷你图，直观反映该属性当前值（如 justify-content: center → 子项水平居中）。
  • 总效果徽标：display: flex 行尾显示 flex 总效果 徽标，汇总整个容器所有 flex 属性的综合布局。
  • 可交互弹窗：点击任意预览弹出配置面板，可实时切换 justify-content / align-items / gap / direction，画布即时重排；点「应用并写回」通过 WriteCommandAction 写回 CSS 文件。
  • 实现层：静态预览用 InlayModel.addAfterLineEndElement + 自定义 EditorCustomElementRenderer；交互用 JBPopupFactory 弹窗，面板为自控 JComponent；值→布局映射为纯逻辑，可用现有纯 Java 验证器测试。
