One-file migration for Vue SFCs still using <style scoped>: all static class="..." attributes that reference classes defined in the current style block are rewritten to :class="$style.xxx" (with $style["kebab-name"] for kebab-case names), and the style tag is upgraded from scoped to module in a single atomic transaction.
Safe-skip rules: dynamic :class / v-bind:class bindings, template interpolations ({{...}}), and classes that have no matching definition in the current scoped style (Tailwind utilities, third-party component class names, etc.) are left untouched.
