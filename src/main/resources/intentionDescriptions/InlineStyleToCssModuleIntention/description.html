Extracts the inline style object (style={{ ... }} in React/TSX or :style="{ ... }" in Vue) into a CSS Module class.
  • Automatic semantic class name inference (from component name, siblings, and style property semantics).
  • Rename-style input dialog lets you tweak the name before committing.
  • Appends the rule to <style module> (.vue) or the imported *.module.css/.scss/.less file.
