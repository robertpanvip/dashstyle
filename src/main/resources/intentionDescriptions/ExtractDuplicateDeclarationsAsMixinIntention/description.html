Scans the current CSS/SCSS/LESS file (or the selected portion) for rulesets sharing exactly the same declaration block body and factors them out into a single shared Less-style mixin (e.g. .shared-padding { padding: 10px; }), replacing each original ruleset's body with a mixin call (e.g. .shared-padding;). Nested blocks, strings and function calls like linear-gradient(...) / url("...") are preserved verbatim during comparison.
